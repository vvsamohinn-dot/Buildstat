# BuildStat

Статический одностраничный рейтинг с ежедневным агентом и публикацией через GitHub Pages.

Проверка: `python -m unittest discover -s tests`, затем `python scripts/build.py`.

Агент ежедневно получает накопленный ввод российских застройщиков из ЕРЗ, отклоняет аномалии и сохраняет прежние значения при сбое. Международные отчёты проверяются отдельно; `OPENAI_API_KEY` зарезервирован для их автоматического извлечения и необязателен. Добавляйте ключ только в GitHub: Settings → Secrets and variables → Actions. Никогда не добавляйте ключ в файлы репозитория.

Для Pages выберите в Settings → Pages источник **GitHub Actions**.
